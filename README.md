# OOTD 今天穿什麼

依當天當地的氣溫，加上自選的色系、風格與版型，推薦一套穿搭。整個網站就是一個 `index.html`，不需要建置步驟。

## 功能

- 台灣 12 縣市快選，也能搜尋其他城市
- 可選今天或之後幾天，以及整天、白天、晚上三種出門時段
- 5 種色系（黑白灰、大地色、莫蘭迪、丹寧藍、軍綠工裝）與 5 種風格（美式、韓系、日系、街頭、極簡）
- 單品平拍與整體預覽兩種檢視，單品依實際尺寸等比例組合，布料以程式產生的紋理呈現
- 保暖度估算、今日提醒與搭配心法，可複製整套穿搭清單

## 天氣資料

- 一般瀏覽器開啟：使用 [Open-Meteo](https://open-meteo.com/) 的預報與地點搜尋，不需要帳號或金鑰
- 在 Claude 裡開啟：透過使用者自己的 AccuWeather® 連接器取得預報
- 連不上時改用內建的中央氣象署預報快照，或切換「自己輸入氣溫」

天氣資料由 Open-Meteo.com 提供，依 CC BY 4.0 授權使用。
